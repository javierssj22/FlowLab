BIENVENIDO A FLOWLAB

Diseña. Conecta. Ejecuta.

  1. Agrega bloques con Espacio, / o doble clic sobre el fondo del diagrama. Arrástralos por el diagrama.
  2. Conecta una salida con una entrada. Naranja = decimal; azul = entero; verde = booleano; rosa = texto; violeta = vector; cian = waveform. Un clic en un cable permite eliminarlo.
  3. Configura cada bloque en el inspector. Usa memoria de un ciclo para realimentación.
  4. Ejecuta en simulación o avanza un paso. El panel frontal reúne tus instrumentos.
  5. Para hardware: carga el firmware y elige WebSocket o WebSerial en el indicador de hardware. WebSerial comunica directamente con USB desde Chrome/Edge; compilar y cargar requiere Arduino IDE o CLI. Después selecciona ESP32 · Hardware.
  6. Guarda tu proyecto como JSON; exporta CSV desde los bloques Registro de datos.

Vector = violeta; waveform = cian. Los proyectos se guardan en archivos elegidos por ti; no se abre trabajo de otra sesión automáticamente.
